### Interactive SVG Big-O Complexity Dashboard

Inspect all functions in the active file sorted worst-first, explore asymptotic growth curves from `O(1)` to `O(2^n)` with the interactive `n` slider, and click any function row to jump straight to its bottleneck.

**3 ways to open it anytime:**
1. Click the **`📊` graph icon** in the top-right editor toolbar.
2. Click **`🔥 Big-O: ...`** in the bottom-right status bar.
3. Run **[Open Complexity Dashboard](command:bigoAnalyzer.openDashboard)** from the Command Palette (`Ctrl+Shift+P`).
